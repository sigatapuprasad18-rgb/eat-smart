# EatSmart — Full-Stack Student Mess Credit Tracker & Meal Suggestor

EatSmart is a full-stack web application designed for hostel students to track mess wallet credits, set multi-tier daily/weekly expense limits, discover personalized High/Medium/Budget meal combinations, and track meal expenses.

## 🛠️ Technology Stack
- **Frontend**: Next.js 14 (React App Router), TailwindCSS, Framer Motion (`framer-motion`), Lucide Icons (`lucide-react`)
- **Backend**: Node.js, Express.js, MongoDB (Mongoose ORM), Cors, Dotenv

## 🚀 Application Structure
- `backend/`: Express REST API running on `http://localhost:5000`
- `frontend/`: Next.js 14 web app running on `http://localhost:3000`

## 🏃 Launch Instructions

### 1. Launch Express Backend Server
```powershell
cd backend
npm install
npm start
```

### 2. Launch Next.js Frontend App
```powershell
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` in your web browser!
